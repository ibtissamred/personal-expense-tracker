# Personal Expense Tracker

A Python application that helps users record, search, and manage personal expenses using an SQLite database.

## Features

- Add expenses
- View all expenses
- Search expenses by category
- Calculate total spending
- Save expense records in an SQLite database

## Technologies Used

- Python
- SQLite
- SQL
- VS Code

## Data Stored

Each expense includes a name, amount, category, and date.

## How to Run

1. Install Python.
2. Download the project files.
3. Open the project folder in VS Code.
4. Open the terminal and run:

`python main.py`

## Project Purpose

This project was developed to practice Python programming, database operations, SQL queries, and data management.
